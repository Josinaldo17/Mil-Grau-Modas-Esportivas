O ** SPORTSTOCK ** é um sistema de gerenciamento centralizado desenvolvido para a loja **Mil Grau**, focado em facilitar o controle de estoque, vendas e fluxo financeiro em uma única plataforma.

---

## 🚀 Sobre o Projeto

O objetivo principal do SPORTSTOCK é profissionalizar a operação da loja, permitindo que vendedores realizem vendas de forma ágil e que gestores tenham controle total sobre o que entra e sai, tanto em produtos quanto em dinheiro.

## 📋 Módulos do Sistema

* **📊 Dashboard:** Visão estratégica com os principais indicadores da loja.
* **🛒 Vendas:** Ponto de venda (PDV) para realizar transações rápidas. O sistema verifica automaticamente a disponibilidade no estoque.
* **📦 Produtos:** Gestão do catálogo, onde ficam armazenados todos os itens disponíveis para venda.
* **💰 Relatórios:** Área dedicada ao histórico de vendas e fluxo de caixa (entradas e saídas de dinheiro).
* **👥 Funcionários:** Cadastro e gerenciamento da equipe.
* **⚙️ Configurações:** Ajustes de perfil do usuário e customização simples do visual do site.

## 🛠️ Como Rodar o Projeto

Siga os passos abaixo para executar o projeto em seu ambiente local:

1.  **Instalar as dependências:**
    Abra o terminal na pasta raiz do projeto e digite:
    ```bash
    npm install
    ```

2.  **Iniciar o servidor de desenvolvimento:**
    Após a instalação, execute:
    ```bash
    npm run dev
    ```

3.  **Acessar o sistema:**
    O terminal irá gerar um link (geralmente `http://localhost:5173/`). Copie esse link e cole no seu navegador para abrir o SPORTSTOCK.
